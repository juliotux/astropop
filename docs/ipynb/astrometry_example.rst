Astrometry notebook
===================

Follow :doc:`../tutorials/astrometry_catalogs/astrometry_net` to solve an image with Astrometry.net,
inspect the solution and use the FrameData or source-list interfaces. It replaces
the notebook's machine-specific paths and corrects its image-dimension handling.

For an executable offline workflow using local counterparts instead of a blind
solver, use :doc:`../tutorials/astrometry_catalogs/astrometric_calibration`.

The numerical examples are maintained in the tutorials; this page preserves
the original notebook URL and section links.
