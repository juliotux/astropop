Dual-beam polarimetry
=====================

Choose half-wave images for a detection-to-linear-polarization workflow, or
quarter-wave beam measurements for linear and circular polarization. These
are separate observing sequences with supplied instrument calibration, independent
of the ordinary CCD stack. Both save Stokes measurements. The images and tables
are in :doc:`../../getting_started/examples`; review the physical conventions in
:doc:`../../modules/polarimetry/index` before fitting.
