Citation and provenance
=======================

The project README identifies the main software reference:

Campagnolo, J. C. N., *ASTROPOP: the ASTROnomical POlarimetry and Photometry
Pipeline*, Publications of the Astronomical Society of the Pacific, 131, 024501.
The article is available through
`DOI 10.1088/1538-3873/aaecc2 <https://doi.org/10.1088/1538-3873/aaecc2>`_
and the `arXiv preprint <https://arxiv.org/abs/1811.01408>`_. The
`repository README <https://github.com/sparc4-dev/astropop#citing>`_ contains
the maintained BibTeX entry and project reference badges.

Cite the scientific methods and dependencies actually used as appropriate to
your work, and record the Astropop version or source commit separately. The
software article does not certify a particular detector calibration, noise
model, catalog selection or instrument pipeline. Use the reproducibility
checklist in :doc:`migration` alongside the citation.
